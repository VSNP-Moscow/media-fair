# Медиаярмарка — сайт с 3 ролями

Полноценный сайт для медиаярмарки без сервера. Работает просто при открытии `index.html` в браузере. Все данные хранятся в `localStorage` браузера.

## Структура

```
media-fair/
├── index.html              # Вход (выбор роли + логин)
├── admin.html              # Администратор
├── participant.html        # Участник
├── volunteer.html          # Волонтёр
├── dashboard.html          # Табло очков (отдельный экран)
├── css/style.css           # Красивые стили
├── js/app.js               # Общая логика ( auth, данные, QR )
├── js/admin.js             # Логика админа
├── js/participant.js       # Логика участника
├── js/volunteer.js         # Логика волонтёра
├── js/snake.js             # Игра «Змейка»
├── js/dashboard.js         # Логика табло
└── js/vendor/qrcode.min.js # Библиотека QR-кодов (встроена, офлайн)
```

## Как запустить

### Способ 1 — просто открыть файл
Дважды кликните на `media-fair/index.html`.  
Работает: вход, админ, участник (QR, викторина, змейка, табло), волонтёр (ручной ввод кода).  
Не работает без интернета: карта OpenStreetMap и сканер камеры волонтёра (html5-qrcode загружается из интернета).

### Способ 2 — локальный сервер (рекомендуется)
Если у вас установлен Python, в папке `media-fair` выполните:

```bash
python -m http.server 8000
```

Затем откройте в браузере:
- http://localhost:8000/index.html — вход
- http://localhost:8000/dashboard.html — табло на отдельный экран/проектор

При сервере будет работать и камера волонтёра, и карта.

## Возможности

**Администратор:** создаёт/редактирует/удаляет пользователей и задания, смотрит краткое табло.  
**Участник:** статичный QR-код на экране, карта заданий с метками, мини-викторина за очки, игра «Змейка» (очки в игре = очки на табло).  
**Волонтёр:** сканирует QR-код участника (камера или ручной ввод), начислит баллы команде за выбранное задание.  
**Табло:** отдельный экран `dashboard.html` с рейтингом команд, местом, количеством участников и очками, автообновление каждые 5 секунд.

## Сохранение данных
Все данные хранятся в `localStorage` браузера. Если очистить данные сайта — данные сбросятся. Кнопка «Загрузить демо-данные» на странице входа восстановит тестовых пользователей и задания.
